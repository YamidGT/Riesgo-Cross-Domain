# Riesgo Cross-Domain

Simulación interactiva que acompaña el paper y poster presentados en la Jornada de Ciberseguridad de la Universidad Nacional de Colombia (JCUN 2026): **"MCP + MHS: Cuando la IA Sale del Software y Toca el Mundo Físico — Nuevos Retos de Ciberseguridad"**.

La página reconstruye, paso a paso, cómo una vulnerabilidad ya documentada en el Model Context Protocol (MCP) podría propagarse hasta convertirse en una acción física no autorizada a través del Model Hardware Standard (MHS) de Anthropic.

Es una simulación ilustrativa y guionizada con fines académicos — no ejecuta ni se conecta a ningún sistema real.

**Autor:** Yamid Alfonso González Torres — Ingeniería de Sistemas y Computación, Universidad Nacional de Colombia, Sede Bogotá.
